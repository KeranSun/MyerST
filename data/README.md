# MyerST data provenance

All datasets are public. Synthetic data is generated by seeded simulators in
`myerst/benchmark/` (deterministic given `seed`).

## Real datasets

### DLPFC 151673 (human dorsolateral prefrontal cortex, 10x Visium)
- File: `data/raw/DLPFC_151673.h5ad` (3,611 spots x 33,538 genes, raw counts)
- Ground truth: `obs['layer']` — 7 cortical layers (L1-L6, WM), Maynard et al. 2021 manual annotation
- Source: spatialLIBD project (Lieber Institute). Original: http://spatial.libd.org/spatialLIBD/
- Downloaded via hf-mirror.com mirror of `spatialLIBD/DLPFC_151673` dataset (Zenodo backend)
- Reference: Maynard KR et al., Nat Neurosci 2021

### Xenium FFPE Human Breast Cancer Rep1 (10x Xenium, subcellular)
- Files: `data/raw/xenium_breast/` — `cell_feature_matrix.h5` (167,782 cells x 313 genes),
  `cells.csv.gz` (x/y centroids), `xenium_rep1_celltype_major.csv` (EMBL annotation, 9 types)
- Source: 10x Genomics datasets CDN (cf.10xgenomics.com/samples/xenium/.../Xenium_FFPE_Human_Breast_Cancer_Rep1/)
- Annotation: EMBL spatialdata-sandbox (s3.embl.de/spatialdata/.../xenium_rep1_celltype_major.csv)
- Reference: Janesick A et al., Nat Commun 2023
- Note: 10x CDN needs browser User-Agent; large files via HTTP Range chunks

### Xenium FFPE Human Breast Cancer Rep2
- Files: `data/raw/xenium_breast_rep2/` — same structure (118,752 cells x 480-gene panel)
- Source: 10x CDN `samples/xenium/1.0.1/Xenium_FFPE_Human_Breast_Cancer_Rep2/`
- Annotation: `xenium_rep2_celltype_major.csv`, exported from the official
  `Cell_Barcode_Type_Matrices.xlsx` sheet "Xenium R2 Fig1-5 (supervised)" (20 types,
  role-mapped in `scripts/e11_multi_cohort.py`)

### Xenium Human Lung Cancer (NSCLC, FFPE)
- Files: `data/raw/xenium_lung/` — `cell_feature_matrix.h5` (161,000 cells x 380-gene
  immuno-oncology panel), `cells.csv.gz`
- Source: 10x CDN `samples/xenium/2.0.0/Xenium_V1_Human_Lung_Cancer_Addon_FFPE/`
- No official cell-type annotation -> marker-rule annotation
  (`MARKER_RULES` in `scripts/e11_multi_cohort.py`)

## Processed artifacts (data/processed/)
- `xenium_crop.h5ad` — 25,642-cell tumor-immune interface crop (Rep1), auto-selected window
- `stagate_official_seurat_embedding.npy` — best STAGATE embedding (GMM ARI 0.522)
- `e4_myerson_dlpfc_L5L6.npz` — Myerson node attribution on the L5|L6 band
- `e5_myerson_cache.pkl`, `e5_fidelity_edges.npz` — Myerson v-cache + fidelity data
- `e8_matrix.pkl` — multi-protocol benchmark matrix (Fig 2)
- `e9_ccc_edges.npz`, `e9b_local_ccc.npz` — CCC synthetic validation
- `e10e_ccxcl12.npz` — CXCL12 per-receiver effects (Fig 4)
- `e11_xenium_breast_rep2.npz`, `e11_xenium_lung.npz` — cohort replications (Fig 5)

## Synthetic data (seeded, reproducible)
- `LayeredTissueSimulator` (domain boundaries, tunable redundancy) — used in E1/E2/E7/E8
- `CCCSimulator` (cooperative LR signaling with ground-truth edges) — used in E9/E9b

## Third-party code
- `vendor/stagate/` — official STAGATE source (TF1.x) for reference;
  faithful PyTorch port lives in `myerst/models/stagate_official_pt.py`
